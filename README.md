# Velocity-XOptimizer v-0.2
VELOCITY XOPTIMIZER v0.2

O Velocity XOptimizer é um otimizador para Windows 10 e Windows 11, criado por JonzinhoXD e desenvolvido em Batch (.BAT) para ser executado pelo CMD.

A versão v0.2 reúne ferramentas de limpeza, otimização do Windows e ajustes voltados para jogos e desempenho.

PRINCIPAIS FUNÇÕES

Limpeza

Remove arquivos temporários e caches para ajudar a liberar espaço no disco, incluindo caches do Windows, navegadores, Steam, Spotify, Microsoft Store, DNS e shaders de vídeo.

Também possui limpeza profunda opcional e pode detectar instalações antigas do Windows.

Aplicativos em segundo plano

Reduz aplicativos, tarefas e alguns serviços que permanecem funcionando em segundo plano, ajudando a diminuir o uso desnecessário de memória, processador e disco.

Otimizador do Windows

Modo voltado para jogos, com Modo de Jogo do Windows, desativação de gravação em segundo plano, ajustes de prioridade para jogos, ajustes de rede e sistema multimídia, agendamento de GPU por hardware quando suportado, plano de energia próprio e opção de desativar a aceleração do mouse.

Otimizador do Jon

Modo de desempenho mais agressivo, que também aplica as otimizações anteriores e pode reduzir efeitos visuais e animações, desativar ou colocar determinados serviços em manual, reduzir programas na inicialização, ajustar tarefas agendadas e ajustar configurações de energia, processador, PCIe, USB e disco.

Também possui opções adicionais para hibernação, serviços do Xbox e Integridade de Memória do Windows.

Restauração

As principais otimizações salvam os valores anteriores para permitir a reversão posteriormente.

O programa também possui histórico das ações, backups internos e pode criar um ponto de restauração do Windows antes das otimizações mais importantes.

Reaplicação automática

Quando determinadas otimizações permanecem ativas, o Velocity XOptimizer pode reaplicá-las automaticamente no login do Windows.

IMPORTANTE

O programa não faz overclock e não ultrapassa os limites físicos do hardware.

Os resultados de desempenho variam de acordo com o computador, drivers, versão do Windows e programas instalados. O projeto não promete uma quantidade específica de FPS.

Algumas opções mais agressivas podem alterar recursos do Windows. Leia as informações mostradas pelo programa antes de confirmar.

REQUISITOS

Windows 10 ou Windows 11.

Permissão de administrador.

Algumas alterações exigem reinicialização do Windows.
